📌 Overview

This project was originally built during a hackathon as part of the PIAcademy. The repository contains a demo of a flame character rendered on an HTML canvas. We also included Chrome extension files to showcase how the animation could be integrated into a browser environment.

The goal of this project was to prototype an interactive flame character that could later be expanded into a more engaging platform.

🛠️ Features

🔥 Flame animation displayed on HTML canvas

🌐 Chrome Extension Demo to run the animation directly inside the browser

💡 Serves as a proof of concept for future interactive educational or entertainment tools

🚀 Getting Started
Run the Demo in Browser

Open html in your browser.

You should see the flame extension animated on the canvas.

Run as a Chrome Extension

Open Google Chrome and go to chrome://extensions/.

Enable Developer Mode (toggle in top-right).

Click Load unpacked and select the extension folder.

The extension will appear in your toolbar, and you can launch the demo directly.
